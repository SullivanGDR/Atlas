# Logos du catalogue Iris

## Technologies ajoutées

React, Next.js, Nuxt, Angular, Vue, Svelte, MySQL, MariaDB, MongoDB, SQLite, Redis, FastAPI, Django, Spring, NestJS, Laravel, Express, Node.js, Docker, RabbitMQ, Kafka et NGINX : SVG de marque distribués par [Devicon](https://github.com/devicons/devicon), conservés sans recoloration. Ce catalogue communautaire n’est pas une source officielle des éditeurs. Les URL exactes, figées sur un commit, sont dans `devicon-sources.json` ; licence MIT conservée dans `DEVICON-LICENSE.txt`. Les droits de marque restent ceux des titulaires.

## Sources éditeurs de la première version

Logos téléchargés le 30 septembre 2026 depuis les ressources officielles ci-dessous. Ils identifient les services représentés par l’utilisateur ; aucune affiliation avec Atlas n’est revendiquée. Les marques restent la propriété de leurs titulaires. Les SVG sont embarqués localement, sans recoloration.

- Kubernetes, Envoy, Helm, Argo, Keycloak, Prometheus, OpenTelemetry : [CNCF Artwork](https://github.com/cncf/artwork), répertoire `projects/<nom>/icon/color/`, [directives de marque CNCF](https://www.cncf.io/brand-guidelines/).
- PostgreSQL : [wiki officiel, logo et conditions](https://wiki.postgresql.org/wiki/Logo), fichier `PostgreSQL_logo.3colors.svg`.
- Grafana : [dépôt officiel, grafana_icon.svg](https://github.com/grafana/grafana/blob/main/public/img/grafana_icon.svg), [politique de marques](https://grafana.com/trademark-policy/).

Les composants génériques utilisent Lucide. Un service absent peut être représenté par un composant générique, avec son nom et sa technologie.
